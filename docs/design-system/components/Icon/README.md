# Icon
The built-in 24px line icon set, drawn in `currentColor` with 2px round strokes.

**Provide:** `name`, optional `size` (default 16), `stroke`, and `label` when the icon stands alone (otherwise it is `aria-hidden`).

- Names: check, x, pause, pending, running, dot, star, play, download, external, chevron, plus, search, restore, log, alert, clock, copy, arrow, web, edit.
- Pair icons with words. Status glyphs (pending, running, pause, check, x) are reserved for status.
