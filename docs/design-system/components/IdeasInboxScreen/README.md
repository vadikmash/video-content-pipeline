# Ideas inbox — /ideas
Screen composition: top bar, page head with "Source from web" (primary) and "Add idea", the discovery result notice, the add-idea form (collapsed until asked), the filter toolbar, and the idea list.

- "Source from web" is the primary action even on an empty inbox; the user never has to type an idea first.
- After discovery, the `done` notice stays until dismissed: "Sourced N ideas · X added · Y skipped as duplicates".
- Filters: status `Segmented` with counts, then Domain and Origin selects. Filters persist in the URL.
- The add-idea form opens as a `Panel` above the list, not a modal, so the list stays visible.
