# EmptyState
What a list or artifact panel shows before it has content, with the one action that fills it.

**Provide:** `title`, `children` (one sentence), optional `icon`, `action` (a Button), `compact` for inside panels.

- Projects empty: "No projects yet" → primary "Pick an idea".
- Ideas empty: "Inbox is empty" → primary "Source from web", secondary "Add idea".
- Artifact not produced: compact, names the stage that will produce it.
