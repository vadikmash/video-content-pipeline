# Remotion skills

For animation, composition, caption, audio, or rendering work, load `remotion-best-practices` from the installed Codex skills and follow its task-specific references. The upstream source is [remotion-dev/skills](https://github.com/remotion-dev/skills).

- Use `remotion-markup` for narrative SVG animation, layout, media, and timing.
- Use `remotion-captions` for subtitles and `remotion-interactivity` for Studio editing.
- Use `remotion-studio` for previews and `remotion-render` for exports and verification frames.
- Use `remotion-docs` to check APIs against the project's installed Remotion version before adopting examples. Use `remotion-saas` for pipeline and renderer integration.

Drive animation from Remotion frames and the composition FPS. Match narrative cues to the stored narration timings. Verify visual changes in a preview or rendered frames, including caption clearance and scene transitions.

The skills are installed in the user's Codex skills directory, normally `~/.codex/skills`. To set up another machine, install the skills from the upstream repository before beginning Remotion work.
